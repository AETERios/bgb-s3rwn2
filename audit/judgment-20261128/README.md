# 判断题订正与直接作答（2026-11-28，r24）

开始练习后直接作答，提交后显示答案和订正；主动打开知识卡的功能保留。旧的 learnFirst=1 设置不会再自动展示答案，不清理或重置学习数据。

新增独立的 judgment-explanation-data，不修改原有八份 JSON。旧题号、题型、选项、答案、原文、范围、笔记及种子数据保持不变。

核对范围为全部 1,688 道原答案为“错误”的判断题：

- 406 道采用原资料给出的订正，118 道保留已有核实说明，1 道新增联网核实说明。
- 695 道给出题库内有正确答案的完整原文、来源题号和文字差异。这部分是自动交叉匹配，尚未逐题人工审定，不等同于现行规章或考试版本认证。
- 460 道缺乏完整依据、8 道存在题库答案冲突，保留原答案并明确标记。

缺依据/有冲突的题已按条款或题干分组联网检索，检索记录位于 web-search-batches。搜索结果、相似度以及不同适用范围的规章不作为已核实订正。事规中的“运营总部、一般事件、事件苗头”不套用国铁事故等级；2006 年技规或 2026 年征求意见稿不冒充考试指定版本。

构建时只从已有明确正确答案的内容取证，排除负向选择题、派生题以及无法确定多空对应关系的选择题；排除已发现的信号主题错配等候选。尚无充分依据的内容继续保留待核，不编写猜测性的解释。

复现步骤（仓库根目录）：

1. python audit/judgment-20261128/audit_judgments.py
2. python audit/judgment-20261128/build_explanations.py
3. 将生成的 explanations.json 同步到 index.html 的 judgment-explanation-data。
4. python audit/judgment-20261128/verify_data.py
5. 配置 PLAYWRIGHT_MODULE 后，用 Node 运行 audit/judgment-20261128/verify-ui.cjs。

data-result.json 验证八份原始数据与 r23 提交逐字一致、证据引文来源、冲突状态及联网检索覆盖；ui-result.json 记录旧偏好直接答题、答前隐藏、答后订正、主动学习卡、原选项、填空焦点、存储保留和桌面布局等浏览器验证结果。

# 电脑默写与番茄专注

入口为 `/desktop.html`，首页和机调合并背诵页均提供链接。版本 `shiguang-unified-20261128-v10-r22`。

默认先背机调合并背诵这套 181 个知识组：左侧搜索、筛选，中间大字显示完整背诵原文。点击“背过了，试着默写”后进入三栏默写与对照；也可随时切回“先背原文”。旧版升级时只将学习方式切到先背原文一次，不清空已有草稿、计划或计时，之后记住用户选择。数据直接读取已发布的机调合集，148 组有背诵原文；33 组只有原题，不推测补写原文。支持遮住默写、对照抄写、上一组、整库打乱轮换。逐字对照按字符编辑距离区分错字、漏字、多字，默认比较标点、忽略空白，可主动选择忽略标点；结果不自动标记掌握，也不参与正式题目的复习排期。

每日计划默认工作日 120 分钟、周末 360 分钟，可单日调整。每轮默认专注 25 分钟、休息 5 分钟，可调整；支持开始、暂停、继续、重置和手动切换阶段。阶段结束自动停止，由用户开始下一阶段。采用时间戳结算，后台、刷新仍可恢复；只累计本轮结束前的专注时间，暂停、休息不累计。跨午夜按各自日期拆分，重置不清除已累计时间。每轮时长改动从下一轮生效，重置可立即应用。

默写草稿、学习计划和计时独立存于 `shiguang-desktop-dictation-v1`，不访问或改写 `jidiao-bgb-app-v1`。这些记录只在当前浏览器保存，不自动同步手机。Service Worker 的网络优先导航、`sw.js` 的 `no-store` 保持原样，增加电脑页及其资源的预缓存。

验证：`verify-desktop.cjs` 的 17 项检查覆盖逐字对照、草稿、计划、暂停、阶段结束、跨日、刷新恢复、三列布局、窄屏、离线以及旧数据和存储不变。完整机调合集验证也通过。桌面截图为 `desktop-1440.png`。

修复只显示条款名、不显示题干的问题：所有 181 组均在标题下直接展示来源原题；有问答时优先以原问答题干说明背诵任务，多段内容分别配上对应原题，填空标记仅在展示时变成下划线，选择题同时展示全部原选项。保留原文换行以呈现分条答案。新增全组题干与选项核对，以及机运规第116条的回归检查。

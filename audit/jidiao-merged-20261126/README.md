同组优先保留问答的完整原答案，再加入未被覆盖的填空原文与正确判断。只有原文包含关系成立时才合并展示，不把内容改写成摘要；措辞不同的内容分别保留。选择题及错误判断保留原题和原答案，不据此推测、补写正确条文。33 组没有可直接合成叙述的正文，页面明确提示展开原题学习。

701 道来源条目复用旧题号，新增 77 个独立合集内练习条目，另有 26 道来源重复条目共用这些新条目；总共对应 649 道去重练习。804 道来源原题仍可逐题查阅，单选、多选保留原选项顺序与正确答案。

合集是独立入口，不向旧的全部原题列表重复追加。旧的 13,391 道题和七个已有 JSON 数据块逐字节不变。合集复用旧题号的练习沿用原记录；只在合集出现的条目使用 `JM-` 前缀。存储仍为 `jidiao-bgb-app-v1`，没有清理或迁移用户记录，也不修改考试日期、到期时间或自定义空。展开、查阅及遮住背诵内容不产生学习评分。
